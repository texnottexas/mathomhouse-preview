# Mathom House

Tools and calculators for the mobile game [Top War](https://rivergame.net/), created by **Gikey (s2698/3355)** and **artu (s2698)** with help from friends around the community.

Live site: **https://mathomhouse.github.io**

---

## Calculators

| Calculator | Description |
|---|---|
| ES Calculator | How many shards to reach ES 7? |
| Gem Calculator | Total your gem inventory |
| Equipment Calculator | Time until your equipment can be crafted |
| Components Calculator | How close are you to ROF 10? |
| Resources Calculator | Food, Oil, and Odinium totals |
| Gear (Stat Comparisons) | Compare stats between two gear loadouts |
| VIT Calculator | How much VIT do you have saved? |
| VIP Calculator | Total spending tracker |
| Pets Calculator | Max stats for gold/purple pets |
| Tech Donation Calculator | Time to complete Territorial Expansion / A New Era of Glory |

## Friends' Tools (from Server 2864)

Additional tools hosted at [2864tw.com](https://2864tw.com):

- [Decoration Index](https://2864tw.com/decor-index.html) — all decorations with buff values, upgrade costs
- [Battle Report Viewer](https://2864tw.com/battle-report.html) — full battle breakdown viewer
- [Heroes Database](https://2864tw.com/heroes.html) — hero roster with stats and gear
- [Base Skins Database](https://2864tw.com/bases.html) — castle skins with city skills
- [UD Sector Map](https://2864tw.com/ssc-map.html) — interactive sector map with round history
